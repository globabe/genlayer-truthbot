Truth and Bot Game

​An interactive AI-powered game developed for the GenLayer ecosystem. This project explores decentralized social engagement and AI-human interaction using Intelligent Contracts.
​

​🎮 About the Project

​Truth and Bot is a logic-based game where players interact with AI agents to distinguish between Bot generated responses and Truth.
​
It showcases how GenLayer's Intelligent Contracts can process natural language and logic to create a trustless gaming experience.
​

🏗️ Tech Stack

​Frontend: Built with Lovable (React + Vite)
​Blockchain: GenLayer Intelligent Contracts (Python)
​Styling: Tailwind CSS

​📂 Repository Structure

​contract.py: The core Intelligent Contract logic (Logic).
​index.html & src/: The game interface (Frontend).
​components.json: UI configuration.
